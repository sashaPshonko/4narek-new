# book2: hybrid floors (per-SKU + optional global)

**Status:** LIVE

Абсолютная щель `nac = sell − buyMax`. SKU не баним.

## Полы

1. **Жёсткий** `300k` (+ JSON softMin).
2. **Per-SKU raise** — K-я щель внутри своей книги (`K = clamp(n/3, 3..12)` среди лотов ≥ base).
   Fat (mega/pochti) уходит в 500–800k; volume (sword7/фарм, p10\<1.5M) остаётся ~300k.
3. **Global raise** — общий порог = K-я щель по всей категории (`K = max(2×cap, 2×free, 10)`),
   включается **только если** над порогом хватает лотов на слоты **и** объёмный ярус
   (`p10 < 1.5M`) тоже ещё кормит (`≥ max(need/4, 8)` лотов).

Иначе слоты не пустуют из‑за единого жирного пола, а жир всё равно дороже.
